# Türkiye haritası ve güncel bölgesel izleme

## 1. Amaç

Marmaris odaklı ilk sürümü Türkiye haritasına genişletmek; önemli olaylara ayrı sayfalardan ulaşmak; ücretsiz gerçek uydu gözlemlerini seçili olay pencerelerinde düzenli karşılaştırarak inceleme adayları üretmek.

## 2. Teknik yaklaşım

Next.js statik web, MapLibre harita, açık Earth Search Sentinel-2 Collection 1 L2A ve önceden çalışan Python analizi kullanıldı. Türkiye genelinde piksel taraması yapılmıyor. Dört küçük alan CPU ile izleniyor; API anahtarı, ücretli uydu servisi, GPU ve veritabanı gerekmiyor.

Görsel RGB bağlam içindir. İşaretler gerçek kırmızı ve yakın kızılötesi bantlardan hesaplanan NDVI farkına dayanır. Bulut/gölge maskesi ve ortak 20 m grid üzerinde değiştirilmiş Z taraması uygulanır. Bunlar saha doğrulaması yapılmamış adaylardır; hasar, yangın nedeni veya kesin iyileşme sonucu değildir.

## 3. Uygulama

- `web/components/turkey-explorer.tsx`, `country-map.tsx`: Türkiye görünümü, il/olay/yıl arama, olay türü filtreleri, güncel adaylar ve tarihsel analiz katmanı.
- `web/app/bolge/[slug]/page.tsx`, `event-detail.tsx`, `recent-observations.tsx`: altı kalıcı olay sayfası; güncel gözlemler ile olay döneminin ayrılması.
- `web/lib/events-catalog.json`: Marmaris, Manavgat, Bördübet, Yamanlar, Tuz Gölü ve Erçek Gölü için kaynaklı kayıtlar.
- `analysis/src/doga/monitor.py`, `detection.py`: dört seçili alanın veri kontrolü, kalite kapıları, önbellek ve aday üretimi.
- `web/public/data/`, `data/processed/`: iki gerçek tarihsel analiz, güncel izleme ürünleri ve denetlenebilir kaynak kayıtları.
- `.github/workflows/monitor.yml`: 06.17 İstanbul için günlük kontrol, doğrulama ve veri yayını.

Harita yüksekliğindeki CSS çakışması ve Muğla aday etiketlerinin örtüşmesi görsel kontrol sırasında düzeltildi. Görsel yükleme hataları açıklanıyor. Tarayıcıda eski GitHub kaydının tutulması gerçek kontrolde yakalandı; uzak JSON çiftleri her okumada yeni sorguyla, bölge özetleri kontrol tarihiyle yüklenerek bu önbellek etkisi giderildi. Uzak izleme kayıtları birlikte doğrulanıyor; erişilemeyen kaynak yerine uydurma boş başarı kaydı kullanılmıyor.

## 4. Çalıştırma

Proje kökünde etkin Python ortamıyla:

```sh
doga monitor --config data/monitoring/config.json
python tools/validate_outputs.py --version-monitor-assets
python -m pytest analysis/tests -q
cd web
npm test
npm run typecheck
npm run build -- --webpack
npm run serve
```

Önizleme: <http://127.0.0.1:3000/>. Sunucu kapatılırsa yerel adres çalışmaz. Vercel yayını yapılmadı.

## 6. Çıktı

Altı olay sayfası ve Türkiye haritası; Marmaris ve Manavgat 2021 gerçek tarihsel çiftleri; Marmaris, Manavgat, Bördübet ve Yamanlar için sınırlı güncel tarama. Su olayları kaynaklı arşiv kayıtlarıdır; otomatik su analizi yapılmaz.

15 Kasım kontrolünde Manavgat 22, Bördübet 20, Yamanlar 1 olmak üzere 43 aday bulundu. Yamanlar’ın son çekimi 14 Kasım 2026. Marmaris’te 0–14 gün penceresinde uygun yeni çekim bulunmadı; eski dosya grubu korunup güncel aday sayısı 0 olarak kaydedildi.

Günlük kontrol ile çekim tarihi farklıdır. Kaliteyi geçen yeni görüntü yoksa yeni aday üretilmez. Ücretsiz günlük zamanlama gecikebilir; her gün bulutsuz görüntü garantisi verilmez.
